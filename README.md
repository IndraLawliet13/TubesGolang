# TubesGolang

Aplikasi CLI berbasis Go untuk pengelolaan inventaris toko.

## Overview

`TubesGolang` adalah proyek berbasis Go yang berfokus pada pengelolaan data inventaris melalui antarmuka command-line. Repository ini cocok sebagai proyek akademik/final project untuk menunjukkan penggunaan struktur data sederhana, menu interaktif, dan operasi CRUD dalam aplikasi terminal.

## Main Features

- tambah data inventaris
- lihat daftar inventaris
- update data inventaris
- hapus data inventaris
- pencarian data
- menu CLI interaktif

## Tech Stack

- Go
- CLI / terminal-based application

## Repository Structure

```text
TubesGolang/
├── index.go
├── README.md
└── go.mod
```

## Run Locally

```bash
go run index.go
```

Atau build terlebih dahulu:

```bash
go build -o tubesgolang
./tubesgolang
```
